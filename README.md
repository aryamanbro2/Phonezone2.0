# Phone Zone 2.0 — Business Website

This repository contains the website for **Phone Zone 2.0**, a mobile phone store, accessories retailer and mobile repair shop in Sector 7, Dwarka, New Delhi.

## Business information

- **Business:** Phone Zone 2.0
- **Type:** Mobile phone store · Accessories · Mobile repairs
- **Address:** Plot No. 149, Ramphal Chowk Road, Beside SBI Bank, Palam Extension, Sector 7, Dwarka, New Delhi — 110075
- **Phone:** +91 99994 44494
- **Hours:** Daily · 11:00 AM – 9:30 PM

Current stock, pricing, colours, product availability and repair eligibility should be confirmed with the store.

## Website

The site is designed to help customers understand the store, browse product categories and services, and find the physical location. Product imagery and model examples are presentation content and should not be treated as a live inventory feed.

## Tech stack

- TanStack Start
- React
- React Three Fiber / Three.js
- Tailwind CSS
- Lucide React

## Local development

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Run

```bash
npm run dev
```

### Build

```bash
npm run build
```

### Lint

```bash
npm run lint
```

## Deployment

Deploy the built application through the hosting provider configured for this repository.

This repository is the source for the Phone Zone 2.0 business website. It is not a manufacturer website and does not by itself establish manufacturer authorization or reseller status.
